# 🚀 FundSaathi  
### AI-Powered Parametric Insurance for Gig Workers

---

## 📌 The Problem

Gig workers operate in uncertainty.

A delivery partner may work the entire day and still earn significantly less due to external factors like heavy rain, poor air quality, traffic congestion, or sudden restrictions. In many cases, daily income drops by **20–30% despite the same effort**.

There is currently no system designed to handle these small but frequent losses. Traditional insurance is slow, claim-based, and not built for real-time disruptions, leaving gig workers financially exposed.

---

## 💡 What We Are Building

**FundSaathi** is a **zero-touch parametric insurance system**.

Instead of requiring users to file claims, the system continuously monitors real-world conditions. When disruption crosses a defined threshold, payouts are triggered automatically.

**No forms. No delays. No dependency on user action.**

---

## 🔄 System Flow
User Onboards -> Risk Profiling (AI-based) -> Weekly Plan Assigned -> Real-Time Monitoring (Weather + AQI + Traffic + Restrictions) -> Trigger Condition Met -> Trust Score Evaluation (Anti-Fraud Layer) -> Payout Decision -> Instant Credit to User
---

## ⚡ Why This Approach Works

Most insurance systems are reactive and depend on user claims.

**FundSaathi shifts this to a condition-based system:**

- Detects disruption automatically  
- Verifies using real-world data  
- Compensates instantly  

This makes it practical for gig workers dealing with frequent, short-term income loss.

---

## 💰 Weekly Premium Model

The platform follows a weekly structure aligned with gig workers’ earning cycles:

- **Low Risk** → ₹20/week → ₹500 coverage  
- **Medium Risk** → ₹40/week → ₹1500 coverage  
- **High Risk** → ₹70/week → ₹3000 coverage  

Pricing adjusts dynamically based on:
- Location  
- Environmental conditions  
- Work patterns  

---

## ⚡ Parametric Triggers

Payouts are triggered when measurable thresholds are crossed:

- Rainfall > 50 mm/day  
- AQI > 300  
- Temperature > 45°C  
- Government restrictions or curfews  
- Severe traffic congestion

## 🛡️ Adversarial Defense & Anti-Spoofing Strategy

### Why This Matters
Simple GPS verification can be easily spoofed. Fraud groups can fake location data and trigger payouts.

FundSaathi prevents this by validating **patterns, not just data points**.

---

### 1️⃣ Differentiating Real vs Fake Users

The system evaluates:
- Movement continuity  
- Delivery activity  
- Time patterns  
- Device/session consistency  

Each user is assigned a **trust score**, not a binary label.

---

### 2️⃣ Multi-Signal Data Validation

Instead of relying on GPS alone:

- Behavioral data (trip history)  
- Spatial patterns (user clustering)  
- Network signals (IP similarity)  
- Environmental verification (weather, AQI)  
- Historical reliability  

---

### 3️⃣ Detecting Coordinated Fraud

The system detects:
- Sudden spikes in claims  
- Multiple users triggering payouts simultaneously  
- Repeated suspicious patterns  

Actions:
- Reduce trust scores  
- Apply additional validation  

---

### 4️⃣ Fairness for Honest Users

- **High Trust** → Instant payout  
- **Medium Trust** → Delayed payout  
- **Low Trust** → Flagged for review  

No decision depends on a single signal.

---

### 5️⃣ Design Principle

Fraud is:
- Hard to scale  
- Easy to detect in patterns  
- Unprofitable over time
